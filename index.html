Developer documentation

REST API for client company panels

Give this documentation to companies that want to integrate your recharge service into their own software.

Authentication

Every request must include the API key generated from the Companies section. IP whitelist and callback URL should be configured before production use. 

Authorization: Bearer rh_live_company_api_key
Content-Type: application/json

Create Recharge

POST /api/v1/recharge

{
  "client_txn_id": "CLIENT12345",
  "service": "mobile",
  "operator": "airtel",
  "number": "9876543210",
  "amount": 199
}

Check Status

GET /api/v1/recharge/status?txn_id=RH1001

{
  "txn_id": "RH1001",
  "status": "success",
  "operator_ref": "OPR984562",
  "amount": 199
}

Callback Response

Your system posts final status to the client callback URL.

{
  "client_txn_id": "CLIENT12345",
  "txn_id": "RH1001",
  "status": "success",
  "message": "Recharge completed"
}
