How to upload this website under roboticapi.in

Follow these steps after downloading the website files from your computer or repository. Upload only the website files into public_html.

1

Prepare your files

Keep these files and folders together:

index.html
features.html
pricing.html
guide.html
contact.html
assets/
  css/styles.css
  js/main.js
2

Open Hostinger File Manager

Login to Hostinger hPanel, choose your hosting plan, open Websites, select roboticapi.in, then open File Manager.

3

Go to public_html

Open the public_html folder. This is the live website root for your domain.

4

Upload the files

Click Upload and upload the HTML files plus the full assets folder. If you upload a ZIP, extract it inside public_html.

5

Check the homepage

Open https://roboticapi.in. If the old page is still visible, clear browser cache or check that index.html is directly inside public_html.

6

Connect the contact form later

This first version validates the contact form in the browser. To receive messages by email or database, add PHP/Node backend handling in the next development step.

Next development prompt

Recommended prompt for step 2

Ask for: "Design the database and admin dashboard pages for Lapu SIM Recharge Automation with users, wallets, operators, recharge orders, and reports."

Do not upload backend/cpp to public_html

The C++ folder is only a future gateway example. It is not needed for the website upload.
