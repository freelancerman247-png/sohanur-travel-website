# Sohanur Travels Website

Static multi-page website for Sohanur Travels, ready to upload to Hostinger shared hosting.

## Pages

- `index.html` - home page
- `about.html` - company story
- `services.html` - travel services
- `destinations.html` - destination ideas
- `packages.html` - package cards and quote buttons
- `contact.html` - WhatsApp-powered inquiry form

## WhatsApp setup

Open `assets/js/main.js` and replace the demo number:

```js
whatsappNumber: "8801712345678",
```

Use the international format without `+`, spaces, or dashes.

## Contact details

Update the placeholder phone, email, and office location in each HTML file before publishing if needed:

- `+880 1712-345678`
- `booking@sohanurtravels.com`
- `Dhaka, Bangladesh`

## Hostinger deployment

Upload all files and folders from this repository to the `public_html` directory in Hostinger File Manager:

```text
assets/
about.html
contact.html
destinations.html
index.html
packages.html
services.html
README.md
```

No build command or backend server is required.
